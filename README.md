# VALONI-I Auto Servis

Webfaqja zyrtare për **VALONI-I Auto Servis**, Mitrovicë, Kosovë. Zhvilluar nga **PREJ SH.P.K.**

## Webfaqja
- Tri gjuhë: **SQ**, **SR (latinica)**, **EN**
- Diagnostikë kompjuterike, ECU / TCU, chip tuning, FLEX, OBD / BENCH dhe servis mekanik
- Harta Google Maps, kontakte, formular për kërkesë termini (WhatsApp / email)
- Dizajn responsive me logo dhe fotografi ilustruese
- Programimi i çelësave nuk është pjesë e shërbimeve.

`index.html` përmban gjithë kodin HTML, CSS, JavaScript dhe fotografitë e integruara; shfaqet direkt në GitHub Pages, pa build ose API key.

## Publikimi në GitHub Pages
1. Hap [Settings → Pages](https://github.com/xheki007/valoni-i-auto-servis/settings/pages).
2. **Build and deployment → Source:** zgjidh **Deploy from a branch**.
3. **Branch:** `main`; **folder:** `/(root)`; kliko **Save**.
4. Pas publikimit, URL pritet të jetë: https://xheki007.github.io/valoni-i-auto-servis/

Çdo ndryshim i ardhshëm i degës `main` publikohet automatikisht.

## Domaini (do të lidhet më vonë)
- Te **Settings → Pages → Custom domain**, vendos domainin real që do të përdoret.
- Konfiguro DNS te ofruesi sipas kërkesave të GitHub Pages (CNAME për subdomain, A/AAAA ose ALIAS për apex).
- Aktivizo **Enforce HTTPS** pasi të përfundojë konfigurimi.
- Mos vendos `CNAME` të supozuar përpara se të caktohet domaini.
